# Gestion de Pedidos de Pizzeria

## Objetivo

Desarrollar una aplicacion en Java para gestionar pedidos de una pizzeria utilizando pilas implementadas manualmente mediante nodos y listas enlazadas.

La aplicacion permite registrar pizzas, deshacer pedidos, rehacer pedidos y consultar el pedido actual.

## Tecnologias

- Java
- Eclipse Temurin JDK 21
- Visual Studio Code
- Git y GitHub
